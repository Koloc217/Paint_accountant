# Paint Catalog — план

Приложение для каталогизации красок для миниатюр: что есть, сколько банок, в какой коробке. Коробки помечаются NFC-метками (необязательно). Заносить краски можно по фото, без ручного набора.

Не привязано к брендам: справочник растёт из того, что пользователь занёс сам. Внешние каталоги — необязательный импорт для подсказок.

---

## Стек (предварительно)

- **Сервер:** Python, FastAPI, SQLite
- **Распознавание:** zxing-cpp (штрихкоды) + RapidOCR (текст), всё локально, без внешних AI API
- **Поиск по названию:** rapidfuzz (нечёткое совпадение)
- **Веб-интерфейс:** работает по http в локальной сети, без сертификатов
- **Telegram-бот:** заливка фото откуда угодно (бот сам ходит наружу, белый IP не нужен)
- **Железо:** Raspberry Pi 5 8GB

## Модель данных

### Краска (paint)
| поле | обязательное | примечание |
|---|---|---|
| id | скрытое | |
| название | да | |
| производитель | да | свободный текст с автодополнением |
| код/артикул | нет | |
| hex | нет | |
| количество банок | да, по умолчанию 1 | 0 = «есть в каталоге, нет в наличии» |
| хранилище | нет | ссылка на storage; пусто — если меток/коробок нет |
| теги | нет | несколько на краску |

### Хранилище (storage)
| поле | обязательное | примечание |
|---|---|---|
| id | скрытое | |
| название | да | «Коробка 3», «Ящик у стола» |
| метка | нет | NFC/QR со ссылкой на страницу хранилища |
| под рукой | да, по умолчанию нет | ящик/органайзер в прямом доступе |

### Тег (tag)
| поле | примечание |
|---|---|
| id | скрытое |
| название | |
| цвет плашки | |

Связь краска ↔ тег: многие-ко-многим.

**Стартовые теги** (редактируемые): Грунт, Основа, Слой, Контраст, Проливка, Спецэффект, Металлик, Чернила, Лак, Для аэрографа.

**Подсказка тегов по словам с этикетки** (небольшая таблица соответствий, дополняемая): Contrast → Контраст, Shade/Wash → Проливка, Primer → Грунт, Metal → Металлик, Air → Для аэрографа, Technical → Спецэффект.

## MVP — этапы

### Этап 1. Каркас и ручной ввод
- [ ] Репозиторий, структура, установка одной командой, systemd-сервис
- [ ] SQLite-схема: paint, storage, tag, paint_tag
- [ ] Веб: список красок, карточка, добавление/редактирование вручную
- [ ] Хранилища: создание, переименование, флаг «под рукой»
- [ ] Теги: стартовый набор, редактирование, фильтры-плашки
- [ ] Поиск по названию/производителю/коду
- [ ] Фильтры: по хранилищу, по тегам, «под рукой», «нет в наличии»
- [ ] Hex-плашка цвета в списке и карточке

### Этап 2. Хранилища и метки
- [ ] Страница хранилища по ссылке `/storage/<id>` — список красок в нём
- [ ] Генерация ссылки для записи в NFC-метку + QR-код как запасной вариант
- [ ] «Добавить в это хранилище» прямо со страницы хранилища
- [ ] Перенос краски в другое хранилище (в т.ч. в «под рукой»)

### Этап 3. Распознавание по фото (веб)
- [ ] Загрузка фото через штатную камеру телефона (работает по http)
- [ ] Штрихкод → поиск известной краски; новый штрихкод запоминается при подтверждении
- [ ] OCR → строки текста кнопками: «это производитель / название / код»
- [ ] Нечёткий поиск по уже занесённым краскам → топ-3 кандидата
- [ ] Автоподсказка тегов по словам с этикетки
- [ ] Экран подтверждения перед сохранением
- [ ] Если фото открыто со страницы хранилища — краска сразу ложится туда

### Этап 4. Telegram-бот
- [ ] Работа через прокси (SOCKS5/MTProto)
- [ ] Фото или альбом → очередь обработки в фоне
- [ ] Ответ списком распознанного с кнопками «подтвердить / исправить»
- [ ] Выбор хранилища кнопками
- [ ] Команды: поиск краски, «что в коробке N», «что под рукой»

### Этап 5. Импорт справочников
- [ ] Импорт CSV (название, производитель, код, hex) как слоя подсказок
- [ ] Проверить лицензии и форматы: minipainter (data/catalog), mpds (Codeberg)
- [ ] Hex из справочника подставляется при совпадении названия

## В планах (отложено)

- **«Вернуть на место»** — банка, взятая под руку, возвращается в свою коробку. Потребует скрытого поля «родное хранилище» у краски.
- **«Разобрать ящик»** — пачкой вернуть всё, что под рукой, по своим коробкам.
- **Потенциальная замена** — для нужной краски, которой нет, найти близкие по цвету среди своих (ΔE по hex), с учётом совпадения тегов; сначала из «под рукой», потом из коробок.
- **Список покупок** — из красок с количеством 0, выгрузка/отправка в бота.
- **Одинаковые банки в разных хранилищах** — отдельная таблица «где лежит» вместо одного поля хранилища.
- **Hex пипеткой с фото** — с выравниванием баланса белого по белой карточке, помечается как «примерный».
- **Узнавание по картинке** — маленькая модель-эмбеддер (CLIP в ONNX) для повторных банок без штрихкода.
- **Локальная vision-модель** для массовой заливки фото ряда банок (проверить скорость на Pi 5).
- **HTTPS / Web NFC / живой сканер штрихкодов** — через флаг Chrome «Insecure origins treated as secure» или сертификат.
- **Связка с Project Hub** — список красок для проекта покраски.
